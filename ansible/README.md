# راهنمای استقرار جامع و خودکار (Turn-Key Deployment Guide)

این پکیج Ansible طوری طراحی شده است که **هر فردی با هر سطح دانشی** بتواند بلافاصله پس از کلون کردن پروژه از گیت‌هاب، تنها با وارد کردن مشخصات سرور خود، کل پلتفرم (شامل پیش‌نیازها، داکر، پایگاه داده، بک‌اند، فرانت‌اند، گواهی SSL و پشتیبان‌گیری) را **تنها با اجرای یک دستور** روی سرور مستقر کند.

---

## ۱. مراحل استقرار (تنها در ۲ مرحله)

### مرحله اول: تنظیم مشخصات سرور و برنامه
فایل `inventory/production/hosts.yml` را باز کنید و تنها این مقادیر را مطابق سرور خود وارد نمایید:

```yaml
all:
  children:
    servers:
      hosts:
        production-server:
          ansible_host: 1.2.3.4                 # آیپی سرور شما
          ansible_user: root                    # یوزر سرور (root یا ubuntu یا ec2-user)
          ansible_port: 22                      # پورت SSH
          ansible_ssh_private_key_file: ~/.ssh/id_rsa # آدرس کلید خصوصی شما
          # ansible_password: "پسورد_سرور"     # اگر به جای کلید، پسورد دارید این خط را فعال کنید
```

> **نکته طلایی:**
> - اگر دامنه ندارید، هیچ تغییری در `domain` ندهید! سیستم به طور خودکار از آیپی سرور شما و `nip.io` استفاده کرده و گواهی رایگان معتبر Let's Encrypt می‌گیرد.
> - اگر ایمیج‌های شخصی خودتان را دارید، می‌توانید متغیرهای `backend_image` و `frontend_image` را به آدرس ایمیج‌های خود تغییر دهید.
> - اگر پسوردها و کلیدهای امنیتی را تغییر ندهید، سیستم به طور خودکار رمزهای امن ۳۲ و ۴۸ کاراکتری تصادفی تولید می‌کند.

---

### مرحله دوم: اجرای دپلوی (تک دستور)

کافیست دستور زیر را اجرا کنید:

```bash
./deploy.sh
```

یا مستقیماً با خود انسیبل:

```bash
ansible-playbook -i inventory/production/hosts.yml playbooks/site.yml
```

## ۲. این دستور چه کارهایی را به صورت کاملاً خودکار انجام می‌دهد؟

1. **نصب خودکار پایتون (Python Raw Bootstrap):**
   حتی اگر سرور شما خام و مینیمال باشد و پایتون روی آن نصب نباشد، پیش از شروع، پایتون ۳ و پیش‌نیازها به شکل هوشمند روی انواع توزیع‌ها (`apt`, `dnf`, `yum`, `apk`) نصب می‌شوند.
2. **سازگاری کامل با تمامی توزیع‌های لینوکس:**
   پشتیبانی همزمان از خانواده دبیان (Ubuntu, Debian) و ردهت (Amazon Linux 2023, AlmaLinux, Rocky, CentOS).
3. **ایجاد کاربر و دسترسی‌ها:**
   ایجاد کاربر `deployer` با دسترسی امن به داکر و دایرکتوری‌های پروژه.
4. **نصب و راه‌اندازی داکر و Docker Swarm:**
   نصب کامل Docker Engine، Docker SDK for Python و فعال‌سازی کلاستر تک‌نودی Swarm با شبکه‌های Overlay ایزوله (`traefik-public` و `app-internal`).
5. **پیکربندی امنیت و فایروال هوشمند (Anti-Lockout):**
   تنظیم UFW بدون خطر قفل شدن SSH، تنظیمات سخت‌گیرانه SSH و مسدودسازی دسترسی عمومی به پورت دیتابیس.
6. **مسیریاب Traefik v3 و SSL خودکار:**
   کانفیگ کامل پروکسی Traefik و دریافت اتوماتیک گواهی SSL Let's Encrypt.
7. **اجرای پایگاه داده و Migration خودکار:**
   استقرار دیتابیس PostgreSQL 16 Alpine، اعتبارسنجی اتصال شبکه داخلی و اجرای خودکار آخرین مایگریشن‌های پایگاه داده قبل از بالا آمدن رپلیکاهای برنامه.
8. **استقرار زیرو-داون‌تایم برنامه (Zero-Downtime Rolling Update):**
   راه‌اندازی ۴ رپلیکای بک‌اند و ۳ رپلیکای فرانت‌اند و بررسی سلامت سرویس‌ها.
9. **به‌روزرسانی خودکار هوشمند (Watchtower Service):**
   راه‌اندازی سرویس systemd جهت چک کردن منظم ایمیج‌های جدید، اجرای خودکار مایگریشن و آپدیت تدریجی کانتینرها بدون قطعی.
10. **پشتیبان‌گیری منظم و بازیابی فاجعه:**
    نصب تایمرهای دوره‌ای بکاپ روزانه و لاگ‌برداری ممیزی (Audit Trail).

## ۳. دستورات کمکی

- **استقرار یک نسخه مشخص با تگ ایمیج:**
  ```bash
  ansible-playbook -i inventory/production/hosts.yml playbooks/deploy.yml -e "app_image_tag=v1.2.0"
  ```
- **بازگشت به نسخه قبلی (Rollback فوری):**
  ```bash
  ansible-playbook -i inventory/production/hosts.yml playbooks/rollback.yml
  ```
- **حذف استک‌ها (بدون حذف داده‌های دیتابیس):**
  ```bash
  ansible-playbook -i inventory/production/hosts.yml playbooks/teardown.yml
  ```
